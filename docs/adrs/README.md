# docs/adrs

Architecture Decision Records. **Obligatorio** cuando un cambio toca la arquitectura
(protocolo 4 de [../../.agents/rules.md](../../.agents/rules.md)).

- Nomenclatura: `ADR-001-titulo-corto.md`, numeración incremental.
- Plantilla: [../../.agents/templates/adr-template.md](../../.agents/templates/adr-template.md).
- Un ADR registra contexto, opciones consideradas, decisión y consecuencias; no se borra, se
  reemplaza (marcando "Reemplazado por ADR-XXX").
